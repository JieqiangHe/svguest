Shortcuts and tips

Select

Click
Select what is under the pointer (outlined as you hover)
Right-click
Menu of common actions
Shift+click
Add to or remove from the selection
Ctrl+click
Select its whole group
Drag on empty
Box select everything the box touches (also on a page background); with Ctrl, whole objects; Shift+drag adds, and also starts over objects
Alt+drag on empty
Box select only what is fully inside; View › Box select touches swaps the two
Alt+click
Select the object below; again to go deeper
Esc
Select the enclosing group, then nothing
Ctrl+A
Select all in the group; Ctrl+Shift+A deselects

Move and resize

Drag
Move, also by the centre dot; snaps to the page and objects (Ctrl: off); Shift: 45°
Alt+drag
Move a copy; Ctrl+D repeats
← ↑ → ↓
Nudge 0.1 mm; with Shift 1 mm
Corner handle
Scale (Shift: freely); click it, or double-click a shape, to drag single points
Side handle
Stretch; on text, re-wrap at that width
Other handles
Rotate (Shift: 15°), round a rectangle's corners, move a line's ends (they snap to objects; Shift: 45°), bend it by the diamond in its middle (Shift: symmetric; back onto the line straightens it)

View

Wheel
Scroll (Shift: sideways), or drag the scrollbars
Ctrl+wheel
Zoom (also Alt+wheel, or pinch)
Drag to an edge
Scrolls the view while you move, size or box select
Space+drag
Pan (or the middle button)
Ctrl+0
Fit; Ctrl+1 actual size, Ctrl+= Ctrl+- zoom
Zoom box
Bottom right: type a %, pick one, or drag the slider
Ctrl+R
Rulers: click to pin a guide, click its mark to remove it; Ctrl+' grid
Ctrl+Shift+L
Layers (also F7, or the button at the canvas's top right): every object, front first; click one to select it, click it again to edit its properties in a window
?
This help; Ctrl+K search and run any command

Draw

V T
Select (also Esc); text: click to type or to edit
M L \
Rectangle, ellipse, line; Shift: square, circle, 45°
A B
Arrow, inhibition (blunt end), in one button with the line; ends snap to objects' points and outlines (Ctrl: off) and stay attached as the objects move; moving the arrow itself detaches it; Heads and Scale in Appearance set each end
W E {
Wedge (drag from the thin end), elbow connector (attaches like an arrow; its diamond moves the middle), brace (drag along what it groups: left to right points up)
I
Eyedropper: click an object to give the selection its style; Alt+click gives an object the picked style
C
Crop a photo: click it, drag the handles; Enter applies, Esc cancels
Swatches
Fill and stroke of the selection, or of new shapes; Shift+X swaps, D sets none and black

Ctrl+Shift+=

Left/Center/Right

Font

SVG Chat

AI settings
Your GLM or DeepSeek API key; TBtools' model needs none
Enter
Send; Shift+Enter new line
Chats
minisvg opens on a new chat; the title switches to an earlier one, renames or deletes it; each is kept in this browser (Kept in this browser… saves them as files) and the AI reads only the current one; near the model's context limit a chat is summarised and continues in a new one
Attach
An image to redraw or a text file to draw from (or paste, drop)
Selection
Select objects first to ask about them or have them changed in place
Read images with
A model that reads an image first, for a drawing model that can't
Long replies
Cut off at the token limit, they continue automatically, up to 3 times
Waiting
A seconds counter shows it is working; Stop cancels

Kept in this browser

Open recent
SVG Chat

A web page can't write files to your disk by itself, so minisvg keeps these inside this browser, in its own storage for this site (IndexedDB databases msbDocs and msbChats), not in a folder: the browser keeps them in its profile in a form other apps can't open. Save as files downloads them as a .zip: the SVG copies, or each chat as a web page with its figures.

Each browser, private window, TBtools and downloaded copy of minisvg keeps its own; clearing this site's data in the browser deletes them. File › Auto-save turns the copies of open files on or off; in Chrome or Edge, File › Auto-save to a folder also writes the open file into a folder you pick, with your permission.
